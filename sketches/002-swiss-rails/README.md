## Variant: Swiss rails (bare content, no cards)

### Design stance
International-style grid: hairlines instead of shadows, one square lead photo, everything else is type. The site reads like a printed index.
### Key choices
- Layout: fixed 210px left rail (sections + elsewhere) + numbered story list; 2px rules as separators
- Typography: Fraunces for titles/wordmark, tabular numerals on the index column
- Color: cream paper, near-black ink, single caramel accent used only for kickers/active rail
- Interaction: rail filters the list live (count updates), hover underlines the headline
### Trade-offs
- Strong at: scan-ability, information density, almost no visual noise, fastest to load
- Weak at: no photo warmth, looks austere for a lifestyle topic
### Best for
- Readers who come to browse many posts; good SEO/first-paint profile
