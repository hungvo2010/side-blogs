## Variant: Bento photo-led

### Design stance
Photo-first magazine grid: one 2x2 feature tile anchors an asymmetric bento, and topic chips re-cut the grid on the fly.
### Key choices
- Layout: 4-col bento (2x2 feature + 2-col wide tiles + 1-col squares + 2 text/CTA tiles)
- Typography: Fraunces titles inside gradient captions, Inter for chips/UI
- Color: same warm tokens, but photos carry the page; two ink-dark tiles for rhythm
- Interaction: chip filter re-flows the grid live; tiles lift on hover
### Trade-offs
- Strong at: appetite, visual richness, mobile-friendly stack, 'looks like a real magazine'
- Weak at: heavy images hurt LCP (needs width/height + lazy), captions unreadable on busy photos without the gradient
### Best for
- Lifestyle/consumer topics where the image sells the click (coffee, food, travel)
