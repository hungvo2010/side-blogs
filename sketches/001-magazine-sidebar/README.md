## Variant: Magazine + sidebar

### Design stance
Print-magazine hierarchy: one dominant lead story, an endless-read column, and a sticky rail for discovery.
### Key choices
- Layout: split lead (text left / 4:3 photo right) + 1fr/340px body-split with sticky sidebar
- Typography: Fraunces display up to 3.1rem (clamp), Inter body, small-caps kickers
- Color: warm cream / ink / burnt-caramel accent (AA tokens)
- Interaction: newsletter form -> toast, row hover shifts title to accent
### Trade-offs
- Strong at: reading flow, 'more to read' signals, newsletter capture
- Weak at: photo impact (only one big image above the fold), heavier DOM
### Best for
- Editorial sites whose value is the writing and whose KPI is return visits + email list
