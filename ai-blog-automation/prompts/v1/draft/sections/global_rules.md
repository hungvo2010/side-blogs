# Global rules (apply to every section you write)
- Write in the publication's voice (from the system prompt) and its language.
- Factual claims need a citation as a real markdown link with a short anchor: [anchor text](url) — never a bare URL, never "[Source: URL]".
- No filler: no "In conclusion", no "Whether you're a …", no restating the same idea twice.
- Short paragraphs (2-3 sentences). Concrete specifics over vague adjectives.
- Do NOT add an H1 or a "## " heading unless this section's instructions tell you to. Start directly with your section's content.
